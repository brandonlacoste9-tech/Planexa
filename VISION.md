# Planexa 2.0 Vision

Planexa 2.0 = Calendly’s simplicity + Québec identity + premium visual comfort + modern tech — built for people who stare at their calendar all day.

## 1. Québec‑First Identity

- Full French‑first experience
- Local tone, local UX, local culture
- Built for Montréal, not Silicon Valley

## 2. Visual Comfort System

Because people will be staring at it:

- **Light Mode** — clean daytime
- **Dark Mode** — soft evening
- **Midnight Mode** — deep navy + neon accents
- **High‑Contrast Mode** — maximum readability
- **Accent Colour Picker** — blue, purple, green, gold, etc.
- **Font Size Slider** — small / medium / large

## 3. Modern, Premium Aesthetic

- Softer edges
- Computer‑glow highlights
- Smooth animations
- Better spacing
- More readable typography

## 4. Faster, Cleaner Tech Stack

- Cloud SQL (Montreal)
- Cloud Run backend
- Prisma
- TypeScript
- Modern API architecture

## 5. Human‑First Experience

- Warmer tone
- Clearer flows
- Less corporate
- More local personality
